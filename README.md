# 💻 Data Structures & Algorithms (DSA)

A structured collection of core data structures, graph algorithms, trees, sorting algorithms, string manipulations, and laboratory assignments implemented from scratch in C.

---

## 📚 Contents

The repository includes implementations of:
* **Graph Algorithms:** BFS, DFS, Dijkstra, Kruskal, Prim
* **Linear Data Structures & Strings:** Array, Linked List, Stack, Queue, String operations
* **Matrix Operations:** Saddle Point, Sparse Matrix
* **Recursion:** Fibonacci, Sum using Recursion
* **Sorting Algorithms:** Bubble, Heap, Insertion, Merge, Selection Sort
* **Tree Data Structures:** BST (Min/Max), Expression Tree Evaluation, Huffman Coding, Tree Traversals

---

## 🛠️ Language Used

* C
